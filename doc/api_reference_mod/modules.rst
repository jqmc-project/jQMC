API reference for modules
================================================================================

Module-level reference generated from the docstrings of the ``jqmc`` core
package (drivers, wave-function components, Hamiltonian terms, converters) and
of the ``jqmc_workflow`` automation package. The curated public API of
``jqmc`` is summarized separately in :ref:`api_reference_link`.

.. note::

   In the ``jqmc`` package, everything except the names listed in
   :ref:`api_reference_link` is internal machinery: these functions and
   constants are shown for reference and may change between releases
   without notice.
